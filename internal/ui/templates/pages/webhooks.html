A failed delivery is retried up to {{.MaxAttempts}} times over about an hour (61 minutes), then abandoned; the log is kept for {{.Retention}} days. Up to {{.MaxWebhooks}} fit in a workspace.

The endpoint must be publicly routable. A URL naming a private, loopback or link-local address is refused when you register it, and the address it resolves to is checked again every time this server opens the connection — so a name that later points somewhere private is not delivered to either.
