# M37 — Dimension visualizations, with the rollup cadence fixed first

**Depends on:** nothing. **Discharges:** Analytics scope row *Dimension
visualizations*; the Accepted-unassigned *dimension rollup cost* row; the known
limitation that the rollup grows with traffic.

The order inside this milestone is the point: the map must not launch reading a
job that overruns its own interval.

## Done means

### First, the rollup

- Dimension rollups move to a **longer cadence** than link and workspace totals —
  the recorded split-cadence option, chosen over a narrower window.
- A staleness metric exists, with a documented alert recipe in
  [operations.md](../../operations.md).
- A re-measurement at the 5.7M-event seed shows the dimension job no longer
  exceeding its interval, recorded in [slo.md](../../slo.md). The narrower-window
  option is the recorded fallback if cadence alone does not hold.

### Then, the presentation

- A country choropleth rendered as **server-computed inline SVG** from a vendored,
  pinned, checksummed world-map path asset, acquired like htmx via a
  `scripts/get-*.sh`. Licensing and size are checked before it is committed — it
  is the product's first vendored data file.
- Shaded by share of clicks, with a unique-visitors layer that carries the
  daily-estimate caveat **verbatim**. Shading by an estimate without repeating the
  caveat would launder an estimate into a fact.
- With no GeoIP database configured the map states data is unavailable, exactly as
  the ranked list already does — tested. No world uniformly coloured "unknown".
  *(Narrowed 2026-08-10 at [M58](m58.md), by
  [F160](../deferred-findings.md#closed) and not by a change of mind here. The
  test the bullet asked for was written against the **configuration**, and an
  instance holding resolved country history with no database — the demo among
  them — was shown the sentence over data that was present. Both surfaces now
  follow the data: the sentence is reached only when no country resolved **for
  that link in the window on screen** and no database is configured, which is the
  state this bullet was describing. *Window* rather than *history* is a
  correction to this note made 2026-08-10 in the same milestone — it read "no
  country in the history", which is wider than the predicate, and the residual
  behaviour is [F195](../deferred-findings.md#open). What the bullet claimed of
  that state is unchanged and still tested.)*
- The ranked list stays one click away from every visualization: it is the view
  that answers "exactly how many".
- Richer charts for the other dimensions follow the existing Go-computed-geometry
  idiom.
- **No new columns.** `link_dimension_daily` already carries clicks and unique
  visitors per value per day.

## Risks

The map asset's licence is a blocker if it turns out wrong, and it is easier to
check before committing than after shipping.

# Reopened — 2026-08-11

**The map has drawn two of its countries as full-width bands since it
shipped.** [F210](../deferred-findings.md#open): Fiji and Russia cross the
antimeridian, `mapgen` emits their rings unsplit, so each path wraps
180→-180 and its fill sweeps the map as a horizontal band — measured on the
rendered SVG: exactly two paths wider than 900 of the 1000-unit viewBox,
Fiji at y≈278 and Russia at y≈8. Faint at 1280px, obvious at 1920, which is
how it survived every 1280-wide look. Work below carries M37's number.

**Reviewed by [M57.9](m57.9.md)'s re-run, deliberately outside W44's
letter**: the latest review whose range contains M37 is Phase 2's M44.9,
`done` in a released phase, and reopening it would spend a review crossing
a phase boundary to read one diff. M57.9's owed-list extends to this
reopening instead, and M44.9's row carries the note — the same shape M51.9's
row already carries. Recorded in decisions.md.

## Done means, as reopened

- **`mapgen` splits any ring that crosses the antimeridian** into parts on
  each side before projecting, and `countries_gen.go` is regenerated. Fiji
  and Russia render as their shapes; every other country's geometry is
  byte-identical or the difference is explained.
- **A test asserts no ring — no subpath of any generated path — has a
  bounding box wider than half the frame**; the widest real ring is
  Russia's mainland at 424.2 units and a wrapped ring measures ~1000, so
  nothing sits between the bound and the defect. *(Amended at acceptance,
  2026-08-11 — the bullet read "no country path's bounding box spans the
  full viewBox width", and a correctly split Russia or Fiji legitimately
  touches both frame edges, so the bullet as written fails on the fix it
  exists to protect. The ring is the unit that can carry the claim; see
  decisions.md.)* The next antimeridian-crossing addition cannot regress
  silently.
- **Looked at, not inferred**: the analytics map is rendered in a real
  browser at ≥1920px and the bands are gone — the kept-spec idiom, or a
  recorded look, whichever the build finds proportionate; which it chose is
  stated.
- The asset pipeline's provenance claims stay true: the licence and
  checksum story `m37.md` records is untouched — this edits the generator,
  not the source data.

## Risks, as reopened

**Low and mechanical.** Splitting at ±180 is well-trodden geometry; the risk
is a country *near* the meridian acquiring a hairline seam, which the
≥1920px look is there to catch. The regenerated file is large and the diff
unreadable — the width test is what stands in for reading it.
