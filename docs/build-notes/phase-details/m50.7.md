# M50.7 — The QR tab stops costing more attention than it is worth

**Depends on:** [M49](m49.md) *(second reopening — the size control this
milestone re-lays-out is the slider that reopening builds)*, [M50](m50.md)
*(reopening — the codes list this milestone re-lays-out is the list that
reopening makes fully removable)*. Both edges are **hard**: building this first
would lay out controls that are about to change shape.
**Discharges:** [F224](../deferred-findings.md#open), owner-approved as work
2026-08-12. Owner-added scope the same day.

Every item here is on a surface some shipped milestone claims — the tab strip is
[M47.5](m47.5.md)'s, the panel content [M48](m48.md)'s, the codes list
[M50](m50.md)'s, the size and download controls [M49](m49.md)'s. **None of them
is defective.** Each does what its milestone claims, which is why this is one
milestone rather than four reopenings: what the owner reported is that the tab
asks for more attention than it returns, and that is a claim about the whole
surface rather than about any milestone's promise.

## Done means

### The list is one click target, and the destructive control is not next to it

- **A row selects on its whole area**, not only on the name. Today only the
  name `<a>` at `partials/link_qr.html:123` is clickable while the row
  paints a selected background across its full width — the affordance is
  wider than the target.
  *Enforced by:* a template test asserting the row's selecting element
  spans the row, and that the action cluster is excluded from it.
- **The action cluster has dead space before it.** Today `gap-2` puts a
  destructive **Remove** 8px from a download button on a ~22px-tall row.
  *Enforced by:* the same test, asserting a separating margin class on the
  cluster.
- **Remove becomes a `−` icon button**, with an accessible name. Owner-set.
- **Download becomes one icon button with a menu**, PNG and SVG inside it,
  so a third format later costs a menu entry rather than a third button.
  The menu is a popover — the mechanism the header's menus already use, so
  `script-src 'self'` is untouched and no script is added.
  *Enforced by:* a template test asserting one download control per row
  and both formats reachable from it.

### What saves, saves once

- **Rename goes.** The name field stays and the one save control writes it
  along with the style. Owner-set: *"the 'Rename' button should be removed
  with the 'Save the style' button taking up all saving functions."*
- **That control reads `Save`.** Owner-set, from three offered.
- **`Restore defaults` is always drawn**, disabled with a reason when
  there is nothing stored rather than absent — today it renders only
  `{{if .QRStored}}`, so an unstyled link shows no control and no
  explanation.
  *Enforced by:* a template test rendering both states and asserting the
  control is present in each.

### The tab says less

- **The `N/20` counter goes near the top**, and the prose that carried the
  cap goes. Owner-set: *"'A link carries at most 20' — this text is
  useless where it is."*
- **The paragraph under the preview goes**, and **the encoded URL under
  the picture goes.** Owner-set, both.
- **The duplicated download pair below the preview goes.** It hits the
  same two URLs as the row's controls
  (`internal/httpx/web_links.go:1181-1186`); the row is where a per-code
  action belongs.
- **The four remaining explanatory paragraphs go or shrink** — the
  analytics paragraph, the second-code paragraph, the snapping-and-contrast
  paragraph, and the five-sentence logo paragraph. What survives is what a
  reader cannot deduce from the control it sits beside.
  *Enforced by:* a template test bounding the tab's rendered prose, so the
  reduction is a number rather than an impression.

### Deliberately not done

- **No new capability.** Nothing here adds a format, a setting or a route;
  a menu that will hold PDF later holds PNG and SVG today.
- **The logo controls are not restructured.** The survey found the same
  shapes there — a worded destructive button, a redundant label over a
  self-submitting file input — and they are left alone, because the logo
  surface belongs to [M50.5](m50.5.md) and touching it here would put two
  milestones' work in one commit.
- **No demo seeder row.** [M50](m50.md)'s and [M50.5](m50.5.md)'s rows
  already seed a link with several codes and a logo, which is what this
  milestone re-lays-out; a row asserting the same table would duplicate
  theirs.

## Risks

**A prose-bounding test is a gate on writing.** It fails when somebody adds a
sentence, which is the point, and it will be the first thing a future milestone
wants to raise. The bound is a number in a test with its reasoning beside it, not
a rule nobody can find.

**The popover menu is the only new mechanism.** The header's menus establish that
popovers work inside this CSP, but they are page-level and this one is per-row,
repeated up to twenty times. If twenty popovers on one page turn out to misbehave
the fallback is a single menu that acts on the selected code — worse, and stated
now rather than discovered.

**Removing prose removes explanations somebody wrote for a reason.** The
snapping paragraph in particular explains a behaviour [M49](m49.md)'s second
reopening deletes, so it goes with it; the contrast half explains a refusal that
still exists and cannot simply go. Each cut is judged against whether the control
beside it already says the thing.
