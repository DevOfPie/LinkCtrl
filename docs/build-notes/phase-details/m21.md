# M21 — Audit log: behavior, retention, growth alerting

**Depends on:** nothing. **Discharges:** Security scope row *Audit log — behavior*;
Plan.md M20's promise that changing the root redirect becomes an audit event; the
`partitions.go` "grows until Phase 2" note.

Five later milestones write audit events (M27 invites, M28 members, M30 blocked
attempts, M39 domains, M43 rules) and one reads them. Building the writer last
would mean retrofitting emission into shipped features, so it is built first, and
retention exists before the table has anything to retain.

## Done means

- An internal audit writer exists. Every event carries `actor_label` as a
  snapshot and `ip_prefix` only — never a full address — asserted by test.
- Changing the root redirect writes an audit event, discharging Plan.md's M20 row.
- `GET /api/v1/audit` lists events org-scoped with keyset pagination, gated by a
  new `audit.read` permission. That permission is **non-delegable** to an API key
  under decision D18's first limb — reading the trail exposes an actor's identity
  tied to a `/24`. `NonDelegableScopes` is the only mechanism: the endpoint
  authorizes on the permission like every other endpoint and nothing branches on
  whether the caller holds a session.
- `LINKCTRL_AUDIT_RETENTION_DAYS` takes effect. `audit_logs` joins partition
  retention under its own window, separate from analytics retention, verified by
  a partition-drop test. **Default is 0 = keep forever** (decision D5): an upgrade
  must never silently delete history an operator assumed permanent.
- Because the default is unbounded, growth is observable: a Prometheus metric for
  audit partition size plus a documented alert recipe in
  [operations.md](../../operations.md). The owner-facing notification reading that
  metric lands in [M22](m22.md), which is where notification behavior exists, and
  is on by default at 5 GB (decision D19); it is emailed too when [M26](m26.md)'s
  mailer is configured.
- The `partitions.go` comment and the operations doc are updated to the new truth.
- Event metadata stays jsonb.

## Risks

The permission's delegability decision is permanent vocabulary — get it right
before the seed migration lands. Keep-forever is the safe default only if the
growth alert actually works, which is why the metric is in this milestone and not
a later one.
